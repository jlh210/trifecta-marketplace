# Social/Local Platform Posting Specs

Distilled from three near-identical "Posting Guide" spreadsheets in Julie's Drive (Signature, Luxury, and Prayer candle lines for Custom Candles LA). Each source file pairs this same platform-spec table with a full per-color, per-platform caption/hashtag library (hundreds of rows) — that generated copy is **not** duplicated here (would bloat this file for no retrieval benefit; per `_system/context-architecture.md` §7, load the modeled spec, not the raw generated-copy archive). ## Platform image/video specs (consistent across all three product lines)
| Platform | Photo format | Photo min size | Photo max file | Aspect ratio | Video format | Video limits | Notes |
|---|---|---|---|---|---|---|---|
| Google Business Profile | JPG/PNG/WebP | 720×720px | 5MB | 1:1 square or 16:9 landscape (cover) | MP4/MOV | ≤30 sec, 75MB, 720p min | Cover photo: 1080×608px recommended |
| Apple Maps | JPG/PNG | 800×600px | 10MB | 4:3 or square preferred | Not supported | N/A — photos only | Submit via Apple Business Connect; up to 10 photos |
| Bing Places for Business | JPG/PNG | 720×720px | 5MB | 1:1 preferred, 16:9 accepted | Not direct | Link a YouTube URL | Add YouTube Shorts URL in business description |
| Pinterest | JPG/PNG/WebP | 1000×1500px | 20MB | 2:3 vertical (ideal), 1:1 OK | MP4/MOV/M4V | ≤15 min, 2GB, 1:1 or 2:3 | Pin title ≤100 chars, description ≤500 chars |
| Yelp | JPG/PNG | 800×600px | 5MB | 4:3 recommended | Not supported | N/A — photos only | Caption ≤255 chars, tag product category |
| YouTube Shorts | JPG/PNG (thumbnail) | 1280×720px | 2MB | 16:9 thumbnail, 9:16 video | MP4 (H.264) | 9:16, 1080×1920, ≤60 sec, 256GB | Title ≤100 chars, "#Shorts" in title/description |

## Caption/description formula (observed pattern across the source libraries)
Each product's per-platform copy consistently follows: product name + wax/finish color + size in the title → a short description (material, size, printing method, "Made in LA," shop URL) → a longer SEO description (use case: churches/events/gifting/hospitality, materials, location, CTA) → platform-appropriate hashtags. Worth formalizing as a reusable copy template/skill rather than hand-writing per product — see `_system/context-architecture.md` §7 on reusable skills.

## Posting trackers
Each source spreadsheet also includes a per-color, per-platform tracker (checkbox + date + notes) to log what's actually been posted where — that tracking data lives in the sheet itself and isn't reproduced here.
