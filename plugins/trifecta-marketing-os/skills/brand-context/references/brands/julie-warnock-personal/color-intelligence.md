# Julie Warnock — Color & Storytelling Intelligence

Julie's applied color intelligence, tuned for **founder-voice content** — newsletters, essays, and thought-leadership — not product/visual generation. This is the key design difference from CCLA: same underlying colors, a completely different schema, because the founder brand *tells the color's story* rather than *generating a product image from it*. Applies the shared [[color-intelligence-methodology]].

**Source of truth:** `02-marketing-os/MARKETING OS/services/brand_intel/archives/julie_warnock/color_intelligence.yaml` (629 lines, 43 colors). The live system reads the YAML — if it and this doc disagree, the YAML wins.

## Per-color schema (tuned for founder storytelling)
Each color entry carries four fields — note how different these are from CCLA's product-oriented fields:
- **`emotional_register`** — the feeling the color's story evokes.
- **`newsletter_theme`** — the content theme it anchors (this brand's default channel is email/newsletter).
- **`seasonal_mapping`** — when in the year the color's story lands best.
- **`storytelling_hook`** — the ready-to-use narrative angle (the historical scandal, accident, or forbidden-status that makes it content).

This maps directly to the methodology's finding that Julie's brand leans on the **historical-narrative, linguistic/symbolic, and cultural-political layers** — the story layers — rather than CCLA's psychological/sensory layers.

## Why the founder brand carries this
The color stories are content assets pre-tested by centuries of human attention — exactly the "manufacturing reality meets taste" register Julie's brand runs on ([[julie-warnock profile]]). A single color (e.g. mummy brown, Scheele's green) is a whole newsletter. Note the overlap with CCLA's color set is deliberate: the same amber that becomes a *product image* for Custom Candles LA becomes a *founder essay* for Julie — one company's color knowledge, applied through two brand lenses (`ARCHITECTURE.md` §0).
