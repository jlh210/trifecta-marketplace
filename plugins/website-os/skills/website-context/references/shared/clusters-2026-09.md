## Cross-brand vertical guard — status check
The guard requires: (1) never target the exact same keyword with the same angle on both brands, (2) lock a distributor/reseller angle for BP vs. a direct-buyer angle for CCLA on any shared term. Checked against this pull:
- **Formally respected** in every case reviewed — no single blog post targets the same keyword with the same angle on both sites.
- **Not holding at the ranking level** — see the cross-brand cannibalization finding in both strategy summaries. The guard prevents duplicate content; it does not prevent Google from simply ranking the stronger domain (CCLA) higher on a shared query regardless of which brand's page was "supposed" to own it. This is a real gap between the policy's intent and its measured effect — flagged for your decision, not resolved here.
