# Bath Bomb Content Strategy

Distilled from Julie's Bath Bomb SEO & Content Master Plan. Bath bombs are a **shared product
line — both brands sell them** (confirmed 2026-07-31), so this is a shared knowledge asset the
blog pipeline reads for either brand. Brand-specific bits (voice, internal-link URLs) are
marked per-brand; the structural strategy is common.

## Core idea
Build category authority for **custom logo bath bombs / "branded bath experiences."** Blogs are
the traffic machine (long-tail, educational, audience-language queries); landing pages are the
sales machine (purchase-intent). Every blog links into a landing page + the main product page.

## Product Story System — color → audience → differentiator
Each color unlocks a different audience *and* a different featured-image match (see the image
mapping wired into `../../sops/run-featured-image-intelligence.md`, G11).

| Color | Tone | Target audiences | Differentiator |
|---|---|---|---|
| White | Clean, safe, universal | Hotels, Real Estate, Wellness | No residue/staining — safe for any tub |
| Gold | Luxury, aspirational | Jewelry brands, luxury gifting | Soft metallic premium finish |
| Blood Red | Dramatic, cinematic | Horror films, Halloween | Turns bath into a cinematic experience |
| Black | Bold, editorial | Men's fashion, luxury brands | Minimal, high-fashion aesthetic |
| Custom | Versatile, brand-matched | Events, weddings, corporate | PMS-style brand color matching |

## Blog structural rules (both brands — feed these into the drafting engine)
- **Length:** 800–1,200 words.
- **Purpose:** answer a real question, genuinely helpful — NOT promotional.
- **CTA:** soft, at the end only — e.g. "Looking for custom options? Explore our bath bombs."
- **Formatting:** H2/H3, short paragraphs, clean bullets.
- **Titles:** use the exact titles from the bank below (they're SEO-optimized).
- **Internal links:** every post → 1 landing page + the main product page (see caveat).
- **Keywords:** target audience language ("hotel welcome gift"), not "bath bomb."

## Voice — BRAND-SPECIFIC (do not cross-apply)
- **customcandlesla (luxury):** Avoid "handcrafted / fun / cute / playful." Use "elevated /
  refined / curated." Tone by audience: Hotels/Real-Estate/Wellness = clean, elevated;
  PR = visual, energetic; Corporate = professional; Jewelry/Gold = soft luxury; Black =
  bold/editorial; Blood Red = cinematic. (From the Master Plan, which is CCLA-authored.)
- **bathpromotions (promotional-products B2B):** uses its own established voice via
  `ecommerce-blog-writer` — the CCLA banned-word list above is NOT automatically its rule.
  Confirm BP's bath-bomb voice separately before applying.

## The topic bank — 30 SEO-optimized titles, split by brand
Use titles exactly. `Type` → post style. **`Brand`** = which site owns it (decided 2026-07-31,
differentiate-by-audience: BP = B2B/promotional/corporate/real-estate/events/wellness lane;
CCLA = luxury/hotel/PR/jewelry/fashion/horror/scents lane — no topic overlap, so the two owned
sites never compete). `Links To` = the plan's CCLA landing path; for BP rows, use the matching
bathpromotions.com landing page (URLs TBD) or fall back to BP's main product page.

## Caveats before generating at scale
1. **Landing pages may not exist yet.** The plan is landing-page-first; the "Links To" targets
   are `/pages/custom-bath-bombs-*` on customcandlesla. If a target page isn't live, the
   internal-linking step must fall back to the main product page only — never link to a 404.
   The bathpromotions internal-link targets are different URLs and need confirming.
2. **Cross-brand cannibalization — RESOLVED 2026-07-31.** Differentiate by audience: each of
   the 30 titles is assigned to exactly one brand (Brand column above), so BP and CCLA never
   target the same topic/keyword. Do not publish a title on the brand it isn't assigned to.
3. **Schedule is stale.** The plan's Apr–May 2026 calendar is past; the content bank is
   evergreen, the dates are not. Plan wants 2–3 posts/week (our automation is weekly).
